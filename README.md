# Portofolio Analisis Data 📊

Selamat datang di portofolio analisis data saya! Repositori ini berisi kumpulan proyek pembuatan *dashboard* dan pelaporan analitik yang berfokus pada berbagai departemen operasional manufaktur/pabrik. ### 1. Dashboard Human Resources (HR)
**Deskripsi:** Proyek ini memvisualisasikan data terkait Sumber Daya Manusia (SDM), termasuk tren data tenaga kerja *direct* dan *indirect* di pabrik, rasio pemenuhan tenaga kerja (MPP), performa pencapaian target, hingga pelacakan komplain pelanggan[cite: 1]. 

* **Metrik Utama:** Rasio Direct/Indirect, Tren Karyawan Masuk/Keluar, Rata-rata Pencapaian Kinerja[cite: 1].
* **Kategori Analisis:** SDM, Kinerja Pabrik, Kepuasan Pelanggan[cite: 1].

> `![HR Dashboard](images/hr_dashboard.png)`

### 2. Dashboard Maintenance & Mekanik
**Deskripsi:** *Dashboard* ini berfokus pada efektivitas mesin dan metrik perawatan. Mencakup pelacakan *breakdown* mesin harian, biaya perbaikan berdasarkan area, penggunaan *sparepart* (seperti jarum dan komponen lainnya), serta metrik OEE (*Overall Equipment Effectiveness*)[cite: 1].

* **Metrik Utama:** Waktu *Breakdown*, SLA Perbaikan, Ketersediaan (Availability), Kualitas (Quality), dan Performa (Performance)[cite: 1].
* **Kategori Analisis:** Efektivitas Mesin, Manajemen *Sparepart*, OEE[cite: 1].

*(Tambahkan gambar dari Report Dashboard.pptx di sini)*
> `![Mekanik Dashboard](images/mekanik_dashboard.png)`

### 3. Dashboard PPIC
**Deskripsi:** Proyek ini bertujuan untuk memantau rantai pasok dan akurasi produksi pabrik. Terdapat analisis kedatangan kontainer (ETA vs ATA) dan persentase akurasi antara rencana (ROP) dengan realisasi produksi (POP), serta pemantauan standar *Lead Time*[cite: 1].

* **Metrik Utama:** Status Keterlambatan Kontainer, *Gap* ROP dengan POP, *Actual vs Standard Lead Time*[cite: 1].
* **Kategori Analisis:** Rantai Pasok, Perencanaan Produksi, Logistik[cite: 1].

*(Tambahkan gambar dari Report Dashboard.pptx di sini)*
> `![PPIC Dashboard](images/ppic_dashboard.png)`

### 4. Dashboard Industrial Engineering (IE)
**Deskripsi:** *Dashboard* IE menganalisis kapasitas produksi pabrik secara keseluruhan. Proyek ini memantau tren utilisasi kapasitas mesin, perbandingan MPP *Need vs Actual*, serta laporan indeks biaya produksi untuk kategori reguler maupun *multiproduct*[cite: 1].

* **Metrik Utama:** Kapasitas Ideal vs Aktual, Utilisasi Mesin, Rata-rata Biaya Langsung (Cost DL), Efisiensi[cite: 1].
* **Kategori Analisis:** Rekayasa Industri, Kapasitas Pabrik, Analisis Biaya Produksi[cite: 1].

*(Tambahkan gambar dari Report Dashboard.pptx di sini)*
> `![IE Dashboard](images/ie_dashboard.png)`

### 5. Dashboard Produksi & Penjualan
**Deskripsi:** *Dashboard* komprehensif yang melacak metrik produksi dan proyeksi penjualan. Termasuk di dalamnya adalah proyeksi penjualan harian, analisis absensi karyawan bagian *cutting* dan produksi, serta pemantauan *scrap* produksi dan barang sisa (BS) seperti karpet dan selimut[cite: 1].

* **Metrik Utama:** Total Proyeksi Penjualan, Rasio Absensi (Kehadiran, Izin, Alpa), Total *Scrap* (Kg/Mtr), Persentase Barang Sisa (BS)[cite: 1].
* **Kategori Analisis:** Penjualan, Kehadiran Karyawan Produksi, Manajemen Limbah/Scrap[cite: 1].

*(Tambahkan gambar dari Report Dashboard.pptx di sini)*
> `![Produksi Dashboard](images/produksi_dashboard.png)`

### 6. Dashboard Quality Control (QC)
**Deskripsi:** Fokus pada menjaga kualitas standar dengan melacak tren barang *Out of Control* (OOC), persentase tingkat cacat (*defect rate*), dan *gap* target cacat baik di proses aksesoris, pemotongan (*cutting*), maupun penjahitan (*sewing*)[cite: 1].

* **Metrik Utama:** % Total Defect, Tren Gap Defect Proses, Kategori Cacat Paling Sering[cite: 1].
* **Kategori Analisis:** Jaminan Mutu, Kontrol Proses Manufaktur[cite: 1].

*(Tambahkan gambar dari Report Dashboard.pptx di sini)*
> `![QC Dashboard](images/qc_dashboard.png)`

---

### 7. Dashboard Performa Administrasi
**Deskripsi:** Proyek untuk memantau performa dan produktivitas tim administrasi (Admin AX). Memvisualisasikan rata-rata waktu penyelesaian *task* (dalam hari), frekuensi jenis jurnal/transfer, serta beban kerja harian dan jam sibuk per admin[cite: 1].

* **Metrik Utama:** Total Tugas Selesai, Rata-rata Waktu Selesai (Hari), Jumlah Tugas/Admin, Akurasi Tanggal Pengiriman[cite: 1].
* **Kategori Analisis:** Performa Karyawan, Produktivitas Administratif[cite: 1].
