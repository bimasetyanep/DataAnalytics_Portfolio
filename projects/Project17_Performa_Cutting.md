# Project 17: Dashboard Performa *Cutting*

Analisis kapasitas operasional aktual dari *sub section cutting* terhadap target kecepatan standarnya untuk mengukur ketersediaan utilitas ruang mesin.

![Dashboard Performa Cutting](../images/dashboard_performa_cutting.png)

## Isu
Pabrik perlu mengetahui apakah *sub section cutting* sanggup menerima tambahan lonjakan permintaan mendadak (*surge order*) di akhir tahun tanpa harus membeli mesin potong baru.

## Analisis Data
Kinerja tim dan mesin *cutting* terbukti sangat produktif. Output penyelesaian mencatat angka absolut 133.432 Set (setara 540.919 Meter kain terpotong). Indeks kapabilitas (*Ability*) area ini terukur di performa 100%, menghasilkan poin index capaian keseluruhan di atas standar, yakni 122,6.

## Saran
1. **Penundaan Belanja Modal (*Capex*):** Mesin dan tim pemotongan saat ini berkinerja *over-capacity* (Indeks > 100). Jangan alokasikan investasi modal untuk pembelian mesin pemotong kain baru pada kuartal ini.
2. **Manajemen *Bottleneck* Lanjutan:** Karena area *cutting* mampu memproduksi komponen dengan sangat cepat (indeks 122,6), pastikan area selanjutnya (Penjahitan) sanggup menyerap potongan kain tersebut agar tidak terjadi penumpukan tumpukan WIP (*Work in Progress*).
